Scope, source quirks and verification

The main batch completed 2,158 trials and science completed 125. Seven interrupted trials, one retained request-rate failure and 168 science trials marked not run are outside scored comparisons. Seven valid completions lacked all four counterparts. The 28 integrated pilots and earlier setup attempts are separate.

DiscoveryWorld results cover seven themes and completed seeds 0 and 1. Later seeds were queued but not completed. Each harder task allowed 1,000 actions. The custom agent used official completion and procedural scores, with no knowledge judge. Easy completion was 100% for all four models on four shared tasks.

567 groups have byte-identical prompts. Two Space Sick groups vary only in runtime object IDs and observation-list order after normalization; task preambles and official hypotheses match. The JSON also gives the result with these two groups excluded.

FANToM is a deterministic inaccessible-information subset, not the published All score. Mixed KOR requires every question in a prompt to be correct. KOR preserves 12 source gold answers rejected by its scorer. LingOly preserves empty-label behavior and reports a nonempty-label sensitivity. PlanBench uses a simulator checked against all 110 official reference plans.
